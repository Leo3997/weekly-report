**主要观点**：本周玉米期货主力周跌2.1%至2377元/吨，跌破20日均线2399.1元/吨，技术面偏空。核心逻辑在于：一是东北降水偏多叠加低温，市场担忧播种延迟及出苗率，但短期未形成实质性减产预期；二是下游深加工及饲料企业补库谨慎，现货成交清淡；三是外盘高位震荡，但国内供需宽松格局未改，期价缺乏向上驱动。

**策略**：震荡偏空。理由：主力合约跌破20日均线，技术面转弱；现货基差收窄至24.3元/吨，期货升水压力增加；东北天气扰动尚未转化为实际减产，短期缺乏利多驱动。建议关注2370元/吨支撑位，若跌破则可能下探2350元/吨。

## 02 玉米基本面数据

### 国际平衡表
n USDA 2025/26年度全球玉米产量预计12.15亿吨，消费12.08亿吨，期末库存3.12亿吨，库存消费比25.8%，较上月下调0.3个百分点，主要因美国减产预期。

### 美玉米种植
n 截至5月10日，美玉米播种进度49%，低于5年均值54%及去年同期56%，中西部降雨延迟播种，市场担忧单产潜力。

### 美玉米价格
n CBOT玉米500.75美分/蒲式耳，周度上涨2.3%，受播种延迟及小麦走强带动；玉米/小麦比价0.735，处于历史低位，支撑玉米饲用需求预期。

### 国内平衡表
n 2025/26年度中国玉米产量2.89亿吨，进口量1200万吨，消费量3.05亿吨，结转库存1.96亿吨，供需紧平衡，产需缺口约1600万吨。

### 主产区售粮
n 东北售粮进度95%，华北92%，均快于去年同期；基层余粮不足5%，贸易商库存集中，市场供应偏紧。

### 天气
n 东北产区哈尔滨气温偏高1.3°C，但长春、沈阳偏低1.5-2.2°C，降水偏多18-26mm，表层土壤墒情偏低0.14，播种进度受低温延迟；华北呼和浩特气温偏高1.1°C，墒情正常。

### 渠道库存
n 北港玉米库存345万吨，周度下降12万吨；南港库存68万吨，周度增加5万吨，北粮南运发运量回升。

### 流通库存
n 流通环节库存总量约1800万吨，周度下降2%，贸易商挺价意愿强，下游采购谨慎。

### 行业库存
n 深加工企业原料玉米库存天数28天，周度下降1天；饲料企业库存天数32天，周度持平，补库需求有限。

### 产地供应情况
n 贸易商出货意愿偏低，基层上量节奏缓慢，东北地区日收购量不足5万吨，华北地区到车量减少。

### 国内现货价格
n 锦州港2320元/吨，周度涨10元；蛇口港2400元/吨，涨20元；吉林深加工2300元/吨，涨10元；山东深加工2340元/吨，涨20元。

### 基差
n 玉米主力基差24.3元/吨，周度走强8元，现货跟涨期货，但期货升水结构维持，反映远期供应偏紧预期。

### 贸易环节
n 产地-港口贸易利润20元/吨，周度扩大5元；北粮南运利润35元/吨，周度扩大10元，物流成本稳定。

### 进口利润
n 进口玉米到港成本约2100元/吨，较国内现货低220元/吨，进口利润窗口打开，但配额内进口量有限。

### 进口谷物
n 3月玉米进口量68万吨，大麦45万吨，高粱32万吨，小麦18万吨；1-3月累计进口玉米210万吨，同比降15%。

### 进口分类
n 玉米进口以乌克兰为主，占比60%；大麦进口来自澳大利亚；高粱来自美国；小麦进口结构稳定。

### 国产小麦替代
n 小麦-玉米价差-80元/吨，小麦价格低于玉米，饲料企业小麦替代比例提升至15%，压制玉米饲用需求。

### 仓单
n 玉米仓单注册量1.2万手，周度增加0.1万手，仓单量处于低位，交割压力有限。

## 03 淀粉基本面数据

### 淀粉平衡表
n 2025/26年度玉米淀粉产量预计约3200万吨，同比增2.5%，主要受深加工开机率高位支撑。消费端，淀粉糖需求平稳，造纸需求受出口拖累小幅下滑，全年消费约3150万吨。出口量维持50万吨低位，结转库存预计增至100万吨，同比增15%，供需格局偏宽松。

### 开机情况
n 截至5月9日，全国玉米淀粉行业开机率68.5%，周环比降0.3个百分点，但仍处近三年同期高位。山东地区开机率72%，东北地区65%，区域分化明显。预计短期开机率维持高位，因企业加工利润尚可。

### 下游开机
n 造纸行业开工率62%，周环比降1%，受终端需求疲软及出口订单减少影响。淀粉糖行业开工率55%，周环比持平，下游饮料、食品企业按需采购为主。整体下游需求恢复缓慢，对淀粉采购支撑有限。

### 深加工产销
n 样本企业周度玉米淀粉产量约28万吨，周环比微降0.5万吨。企业销量约26万吨，产销率93%，低于上周的95%。库存压力显现，部分企业开始降价促销以缓解资金压力。

### 行业库存
n 深加工企业玉米原料库存平均15天，周环比降1天，因到货量减少。产成品淀粉库存68万吨，周环比增2万吨，同比增12%。华北地区库存压力较大，东北地区相对可控。

### 原料成本
n 玉米现货均价2325.71元/吨，周环比涨10元/吨，受基层余粮减少支撑。东北深加工企业收购价2200-2280元/吨，华北2400-2480元/吨。预计短期玉米价格窄幅震荡，成本端对淀粉支撑有限。

### 成品淀粉报价
n 东北地区淀粉出厂价2850-2900元/吨，周环比跌20元/吨。华北地区报价2950-3020元/吨，周环比跌30元/吨。市场成交清淡，企业为去库存主动下调报价。

### 加工利润
n 山东地区理论加工利润约80元/吨，周环比降20元/吨，因淀粉价格下跌。吉林地区利润约120元/吨，周环比持平，受益于玉米成本较低。行业平均利润处于年内中位水平，短期或继续收窄。

### 现货基差
n 淀粉主力合约基差约-50元/吨（现货-期货），周环比走弱10元/吨。现货价格跌幅大于期货，基差处于近三年同期偏低水平。预计基差短期维持弱势，因现货库存压力较大。

### 替代品价差
n 木薯淀粉现货价3800元/吨，与玉米淀粉价差约850元/吨，周环比扩大50元/吨。价差处于历史中高位，玉米淀粉替代优势明显，但下游替代需求受限于工艺调整周期。

### 仓单
n 截至5月12日，玉米淀粉仓单量约1200手（合1.2万吨），周环比增200手。仓单增加反映企业套保意愿增强，对盘面形成一定压力。预计仓单量短期继续增加。
